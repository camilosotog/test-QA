Cómo Funciona

Se utilizan estilos CSS avanzados para crear una experiencia visual completa:

  • Pseudo-elemento ::after para mostrar símbolos dentro del círculo
  • Selector :has() para colorear el contenedor cuando el radio está marcado
  • appearance: none para personalizar completamente el radio button
  • Box-shadow para efectos de glow y profundidad
